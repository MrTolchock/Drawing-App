# Legacy

Everything here is retired or retained solely as historical provenance. The current game, offline cache, design rules and CI do not load legacy implementations. Current maintenance tools, editable artwork sources and generator recipes stay under `tools/`, `design/` and `tests/`.

| Location | Contents |
| --- | --- |
| [Retired runtime](retired-runtime/) | Drawing engine/templates, palettes, stamps, album wiring, unused landing/colouring/navigation art, retired paint tests and original copies of pruned shared files |
| [Retired design](retired-design/) | Superseded map/portrait preparation attempts, completed draft requests, duplicate map source and unused forward recipes |
| [Design history](design-history/README.md) | Original prompts, source experiments, old visual directions, before images and dated evidence |
| [Legacy game](legacy-game/) | Earlier game implementations and their tests |
| [Retired drawing](retired-drawing/) | Previously retired drawing screens and support |

| [Retired free-play tests](retired-free-play-tests/) | Earlier unrestricted journey tests |
| [Project baseline](project-baseline/) | Earlier project documents |
| [Previous archive index](previous-index.md) | Unchanged original index before the archive moved here |
| [Move and integrity manifest](manifest.json) | Original paths, current locations, SHA-256 hashes and baseline commit |

The former `archive/` tree and newly retired files retain their exact bytes. Historical records may show their original filenames and relative links; use the manifest to locate moved material or inspect the recorded baseline in Git. Original working instructions use inert `.record.md` filenames. Root `AGENTS.md` and `CLAUDE.md` only describe preservation rules.

Old drawings, template IDs, settings and gameplay records remain on existing devices. This repository cleanup does not delete saved data or the GitHub `puzzle-review-data` branch. Current saves remain compatible.

Use the [current design](../design/README.md), [canonical illustration style](../design/illustrations/STYLE.md) and [generator handoff](../design/artwork/GENERATOR-INPUTS.md) for new work. Historical requests explain how existing pixels were made; they must not become forward style inputs.
