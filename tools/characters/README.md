# Current character source

`plush.js` is the maintained sculpt source for the current 13-character cast, promoted from the retired visual-overhaul prototype. `tools/bake/` imports it to create `assets/characters/*.glb`. `tools/portraits/` then renders those exact models into one UI identity atlas.

Follow [Visual style](../../design/VISUAL-STYLE.md). Historical sculpt experiments remain archived; do not point the production tooling back at them.
