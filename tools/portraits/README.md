# Neighbour portraits

`assets/forest-friends/neighbours.webp` holds the five big-world neighbours as plush portraits in the same
3 × 2 layout as `postcard-friends.webp` (512 px cells): Igel, Fisch, Reh / Eisvogel, Frosch, (empty).
They are rendered from the baked models, so they match the 3D characters. To redo them after a bake,
serve the repository root and run `node tools/portraits/render.cjs` (needs Playwright and Pillow-free Node only).
