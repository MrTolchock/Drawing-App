# Working in Waldpost

Follow the [working agreement](CLAUDE.md) and the [current design](design/README.md).

For any image-generator work, start with the [artwork handoff for Claude](design/artwork/README.md). It indexes backgrounds, icons, letters, recorded original prompts, reconstruction recipes and the [central puzzle image library](assets/waldatelier/README.md).

For drawn learning pictures, read the [illustration handoff](design/illustrations/README.md). It includes style references, the actual generation prompts, source PNGs, cell manifests and the atlas-packing command. Image generation requires an image-capable service supplied by the current environment; the repository contains the preparation tools and recipe.
