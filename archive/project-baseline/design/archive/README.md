# Design archive

Dismissed visual alternatives and earlier project material are preserved here.
The [current design index](../README.md) and [current gallery](../heart-tree/GALLERY.md)
present the selected Painted woodland direction and current app first.

| Archived collection | Why it is here |
| --- | --- |
| [Unused visual identities](../../../../design/archive/visual-identities/README.md) | Formenfreude, Papierwelt, Kleine Welten and Tintenabenteuer were not selected; the chosen Waldatelier board is kept in the active design folder |
| [Woodland comparisons and refinements](../../../../design/archive/woodland-studies/README.md) | Earlier three-option studies and A1/A2 refinements were superseded by the user's choice of original A; the original A/B board is kept intact |
| [Early story, world and gameplay options](../../../../design/archive/early-options/README.md) | Mixed comparison boards containing both chosen and unchosen ideas; the current blueprint records the resulting decisions |
| [Earlier detailed storyboards](../../../../design/archive/storyboards/README.md) | Earlier world, opening, library and non-reader illustrations, before the selected calmer woodland treatment |
| [Previous prototype screenshots](../../../../design/archive/prototype-screenshots/README.md) | The earlier geometric 3D presentation and original flat adapters, before the painted update |
| [Earlier and intermediate app captures](../../../../design/archive/verification/README.md) | Historical browser/preview records; canonical current screenshots are in the active gallery |
| [Historical review documents and authoring sources](../../../../design/archive/reviews/README.md) | Original illustrated review PDFs, their covers and source scripts |
| [Implementation and release history](../../../../design/archive/implementation-notes/README.md) | Earlier plans, prototype status, hosting and release records |

**Archived does not mean every idea in a board was rejected.** Mixed comparison
boards remain unedited so the original work is preserved. The user selected
**original A, Painted woodland**, rather than B, A1 or A2. Its left-hand panel in
the [original A/B board](../../../../design/archive/woodland-studies/visual-middle-ground-options.png) remains
the authoritative visual reference. The selected story still uses the woodland
loop, short quest arcs and Meet → Reconnect → Gather.
