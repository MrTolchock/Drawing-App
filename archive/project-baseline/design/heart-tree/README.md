# Der Herzbaum — selected design

**Original A, Painted woodland** is the selected visual direction. The forest
uses a connected loop, short complete helping quests and the chapters
**Meet → Reconnect → Gather**. The child is 6–7, initially cannot read, and meets
Swiss-native neighbours and plants.
