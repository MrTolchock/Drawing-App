# Retired optional play timer

Preserved for history, 12 November 2026. These files are not loaded, precached or part of the active test suite. Old timer preferences stay untouched and have no effect. The active app uses parent-chosen letter sessions: see [Letter sessions](../../docs/LETTER-SESSIONS.md).

The archived browser test describes the earlier timer interface and is not a current acceptance test. Model paths can be adjusted to this folder for historical investigation; Git history retains the complete original runtime.
