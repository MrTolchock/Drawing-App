# Retired game code

Heart Tree screens/story, former activity engines, free-play UI, prior shared-world source snapshots and their tests are archived here. The previous inline puzzle (with hints/demos) and mixed portrait pipeline are preserved for reference. These files are not loaded, imported or precached by the current game.

Shared utilities actually used by Waldfreunde were promoted: scene materials to `js/scene/`, speech to `js/core/speech.js`, touch handling to `js/ui/gestures.js`, icon controls to the common SVG family. The active library is an explicit 34-puzzle inventory, independent of retired generators.

Old story/save records remain untouched on devices. Archived tests describe former behaviour and are not current acceptance checks. See [current development](../../docs/DEVELOPMENT.md) and the [archive manifest](../design-history/manifest.json).
