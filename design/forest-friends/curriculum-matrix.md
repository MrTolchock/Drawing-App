# Curriculum matrix — first-grade Zürich

**Status:** Design mapping checked against official sources on 7 November 2026; teacher review pending. This is an implementation planning document, not evidence of pupil attainment or official approval. One difficulty level. Character names use Swiss Standard German.

The first playable set contains five puzzles, including reading with Maus. All other entries remain a backlog. The ranges below are design choices for first-grade practice, not official annual requirements. Zyklus 1 includes kindergarten and both first primary years. A category reference alone is insufficient to approve a task: the specific action and content must fit the cited step.
