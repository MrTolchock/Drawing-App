# Farbtupf visual directions

> Archived initial comparison. **[Waldatelier](01-waldatelier.png)** was selected. The later [Painted woodland direction](../heart-tree/ART-DIRECTION.md) guides the forest. See the [complete design archive](../README.md).

Five preview-only art directions for choosing one consistent visual system for the whole app. Generated with the built-in image-generation tool. No application screen or runtime asset has been replaced.

Each board compares the same three surfaces: the home screen, Sternenrakete, and the drawing area. A small artwork strip shows how characters, pictures, colouring outlines, tool icons and colours belong to the same family.

1. **[Waldatelier](01-waldatelier.png)** — watercolour/gouache storybook, warm cream, moss and terracotta.
2. **[Formenfreude](02-formenfreude.png)** — Swiss geometric graphic design, precise flat shapes and vivid colour.
3. **[Papierwelt](03-papierwelt.png)** — carefully layered cut-paper artwork, restrained tactile surfaces.
4. **[Kleine Welten](04-kleine-welten.png)** — matte clay miniatures with quiet, clear controls.
5. **[Tintenabenteuer](05-tintenabenteuer.png)** — expressive ink illustration with selective warm colour.

These are visual concept boards. Exact typography, illustration assets, interactions, contrast and responsive behaviour will be refined during implementation after a direction is selected.

The full generation briefs are in `prompts.json`. The application remains unchanged while these directions are compared.
